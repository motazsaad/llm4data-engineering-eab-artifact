# Reproducibility Manifest

This manifest defines the execution environment and immutable input checks for
the ICDE 2027 EAB study. It complements the runnable commands in
[`README.md`](README.md) and [`harness/README_OLLAMA.md`](harness/README_OLLAMA.md).

## Required local services

- Docker Engine with Docker Compose.
- Python 3.
- Ollama serving the OpenAI-compatible endpoint at `http://localhost:11434/v1`.
- An NVIDIA RTX 6000 Ada (48 GB VRAM), 64 CPU cores, and 125 GB RAM were used
  for the reported study. Other hardware can rerun the protocol but is a
  different deployment condition and should be reported as such.

## Fixed execution configuration

| Component | Pinned study configuration |
|---|---|
| Airflow runner | `apache/airflow:3.3.1-python3.11`; `apache-airflow-providers-http==6.0.5` |
| n8n runner | `n8nio/n8n:1.90.1` |
| Recorder network | Docker bridge network `harness` |
| Generation | temperature `0.7`; maximum `8192` tokens; request timeout `600` seconds |
| Headline replication | 5 independent generations per cell |
| Ceiling-model replication | 3 independent generations per cell |
| Repair | at most 2 feedback-based repair rounds |

## Reproduction order

1. Pull the listed Ollama model tags and archive the resolved local manifests.
2. Verify fixture checksums.
3. Run all 12 controls via `harness/selftest.sh`; stop if any control fails.
4. Execute the hermetic baseline matrices for `spacex` and `github`.
5. Run `aggregate.py` and `paper_tables.py` to create the pooled outputs.
6. For repair, run `run_matrix_repair.sh` over failed baseline cells and preserve
   its separate output tree.

All generated artifacts, runner logs, sink observations, scores, and matrix rows
are written below `harness/out/`. This directory is intentionally not versioned:
it is regenerated by the protocol and may contain many model-generated artifacts.
